# FiziSysMaker — Laravel 12 + Filament 4 Boilerplate

A production-ready starter kit for admin-panel-driven web applications, generated by [FiziSysMaker](https://github.com/mohdhafizi83). Ships with a complete Filament 4 admin panel, role & user management, and a print action — skip the boilerplate, start building features on day one.

## What's inside

| Component | Details |
|---|---|
| **Laravel 12** | Fresh framework, PHP 8.2+ |
| **Filament 4** | Admin panel (TALL stack: Tailwind, Alpine, Laravel, Livewire) |
| **Role management** | Full CRUD resource: create, edit, view, list roles |
| **User management** | Full CRUD with form schema + table schema split (Filament 4 pattern) |
| **PrintAction** | Reusable Filament table/action for printable records |
| **Dev tooling** | Pint (formatting), Pail (logs), Sail (Docker), PHPUnit/Pest |

## Requirements

- PHP 8.2+
- Composer 2
- Node.js 18+ (for asset builds)

## Quick start

```bash
# 1. Clone
git clone https://github.com/mohdhafizi83/FiziSysMaker-Laravel-Filament-Boilerplate.git myapp
cd myapp

# 2. Install dependencies
composer install
npm install

# 3. Environment
cp .env.example .env
php artisan key:generate

# 4. Database (configure DB_* in .env first)
php artisan migrate

# 5. Build assets
npm run build

# 6. Run
php artisan serve
```

Admin panel: `http://localhost:8000/admin`

## Structure

```
app/
├── Filament/
│   ├── Actions/PrintAction.php      # Reusable print action
│   └── Resources/
│       ├── Roles/                   # RoleResource + Pages
│       └── Users/                   # UserResource + Schemas/Tables/Pages
├── Http/
├── Models/
└── Providers/
```

## Extending

Add a new resource the Filament 4 way:

```bash
php artisan make:filament-resource Product
```

Follow the existing `Users` resource as the reference pattern (separated `Schemas/` and `Tables/` classes).
